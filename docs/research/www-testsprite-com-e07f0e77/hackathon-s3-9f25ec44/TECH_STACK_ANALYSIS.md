# Technical Stack Analysis

- Source framework: Next.js App Router.
- Source styling: Tailwind CSS with custom semantic color/type utilities and generated grid helpers.
- Source primitives: Radix-style portal/flyout behavior in the navigation.
- Source images: Next image optimization plus static PNG assets.
- Source animation: CSS transitions and data-state enter/exit classes; no dedicated scroll animation library detected.
- Clone equivalents: Next.js 16 App Router, React 19, Tailwind v4, local static assets, `next/font/local`, and small client components only where menu/flyout state is required.
